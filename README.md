A simple analog waveform generator designed using LM741 operational amplifiers.
This project was initially developed in Proteus Design Suite as part of an academic project.
Later, the same project was completely recreated in KiCad EDA as a personal learning project to practice:
1. schematic design,
2. PCB layout,
3. component placement,
4. and manual routing.
Both versions include the complete circuit design and PCB implementation.

# Project Overview

The circuit is an op-amp based waveform generator capable of producing square and triangle waveforms using oscillator and integrator stages.
This project helped in understanding:
1. Analog circuit design
2. Operational amplifier applications
3. RC timing circuits
4. PCB design workflow
5. Schematic capture and routing

# Development Workflow
# Academic — Proteus

# Components Used
1. Op-Amps ---> LM741
2. Resistors	---> 1kΩ, 2.7kΩ, 10kΩ
3. Potentiometers	---> 10kΩ, 100kΩ
4. Capacitors	---> 22nF
